# 平衡之道

一款學騎腳踏車的網頁遊戲。從五歲時爸爸扶著後座的第一圈，一路騎到雨夜裡自己回家。每一章學一個真正騎車用得到的技巧，摔車時會用慢動作重播告訴你原因。

- 畫面：早期賽車遊戲那種偽 3D 追尾視角
- 物理：傾斜、龍頭、抓地力、踏頻與變速都有模擬，騎太慢會倒、彎道太快會滑
- 技術：純靜態網頁，不需要安裝、建置或伺服器

---

## 給玩家

### 怎麼開始

直接用瀏覽器打開 `index.html`，或放到任何靜態網站空間。遊戲進度（通關了哪幾章）存在你自己的瀏覽器裡。

### 操作

| 按鍵 | 動作 |
|---|---|
| `A` / `D` 交替 | 左腳 / 右腳踩踏板。節奏輕鬆就好：45 拍約 13 km/h，60 拍約 14 km/h，再快也只多一點點 |
| `←` / `→` | 身體重心往左 / 往右。車身往哪邊傾，就往哪邊轉；放開就回正 |
| `S`（或 `↓`） | 後煞，主要用這個 |
| `W` | 前煞，很猛，高速時用力按會翻車；雨天會打滑 |
| `F` | 伸腳落地（快停住時再按）；腳踩著地停住時再按一次是蹬地起步，車子先動一點，再接著踩 |
| `↑` | 停著時倒轉踏板，把踏板轉到起步最有力的「兩點鐘」位置 |
| `Z` / `X`、`1`–`5` | 換輕檔 / 重檔（第 4 章） |
| `Q` / `E` | 左轉 / 右轉手勢（第 5 章） |
| `L` | 車燈（第 6 章） |
| 空白鍵 | 鈴鐺 |
| `Esc` | 暫停 |
| `M` | 靜音 |

手機上（橫向優先，直向也可以）：

| 觸控 | 動作 |
|---|---|
| 左半邊任何地方按住，左右拖曳 | 身體重心往左 / 往右，拖越遠傾越多，放開回正 |
| 右半邊左右兩塊交替點 | 左腳 / 右腳踩踏板 |
| 右下角按住（或踩踏的手指往下滑） | 後煞 |
| 右上角按鈕 | 依章節出現：轉踏板、放腳、前煞、換檔、手勢、鈴、車燈 |
| 左上角章節名稱 | 暫停 |

### 六個章節

1. **五歲．後院** 平衡入門。爸爸扶著你，騎到一半會偷偷放手。車往左倒就按 →、往右倒就按 ←。
2. **起步與停車** 起步前把踏板轉到兩點鐘、用後煞減速、快停住才伸腳，在三個停車格內停好。
3. **公園彎道** 學會用傾斜轉彎。按 → 時注意前輪：它會先往左一下（反向轉向），再轉向右邊。
4. **上坡下坡** 上坡換輕檔才踩得動；下坡會越衝越快，彎道前要點放煞車，一直捏著煞車會過熱。
5. **城市通勤** 紅綠燈、斑馬線上的行人、路口轉彎前打手勢、路邊停車突然打開的車門。有安全分數。
6. **雨夜挑戰** 打開車燈、濕地抓地力差、水坑和人孔蓋上更滑，傾斜著踩上去最危險。

### 小提示

- 騎太慢很容易倒，保持穩定的踩踏節奏。
- 進彎前先看黃色預告牌上的建議速度，彎道外側的黃黑箭頭牌告訴你彎往哪邊。
- 輪胎快抓不住時會發出尖銳的摩擦聲，車身也會開始晃，這時要先減速或少傾一點。
- 摔車重播可以按 `Enter` 跳過。

## 給開發者

### 執行與測試

```bash
# 直接玩：用瀏覽器打開 index.html 即可（一般 <script>，不是 ES 模組，file:// 也能跑）

# 測試（兩種方式擇一）
open tests/index.html          # 瀏覽器版測試頁
node --test tests/engine.test.js   # Node 18 以上
```

### 每一幀發生什麼事

```
按鍵 ─► game.js step()（依實際經過時間切成最多 1/120 秒的小步）
          ├─ engine.smoothInput     方向鍵 → 想要的傾斜方向
          ├─ engine.stepSpeed       踏頻、檔位、坡度、煞車 → 速度
          ├─ engine.stepLean        騎士反射、重力、抓地力 → 傾角
          ├─ engine.stepMove        傾角 → 轉彎 → 沿路距離 s、橫向 d、車頭夾角 psi
          ├─ camera.follow          鏡頭橫向慢慢跟上車子
          └─ 各章規則（停車格、紅綠燈、行人、水坑……）
render() ─► camera.points  取樣前後道路
          ├─ 天空與遠景（跟著車頭方向轉）
          ├─ 路面（逐條掃描線）
          ├─ 路邊物件、腳踏車（由遠到近，被坡頂擋住的部分裁掉）
          └─ hud.js 儀表
```

### 物理模型（engine.js）

座標用「道路座標」：`x` 是沿路距離、`d` 是離道路中心的橫向距離、`psi` 是車頭和道路方向的夾角。賽道是每公尺一格的曲率 `k` 與坡度 `gr`。

**傾斜**（每一步）：

```
傾倒加速度 = gravity(v)·sin(傾角)  − STEER·(STEER_BASE + v)·龍頭  − SELF·v·傾角
           − damping(v)·傾倒速度  + 方向鍵·BODY  + 隨機擾動·noiseScale(v)
```

- **騎士反射 `riderSteer`**：方向鍵代表想要的傾角（按滿是 `LEAN_TARGET`）。騎士算出要把傾角帶到目標所需的龍頭量：想往右傾時先往左反打，車身倒下去之後回正撐住。按著方向鍵時全力配合，放開時只出 `ASSIST` 比例的力；速度越慢力道越小。
- **低速**：`gravity(v)` 在 `V_SLOW` 以下額外加 `G_SLOW`，阻尼也變小；方向鍵的 `BODY` 推力在高速時會被騎士抵消，低速抵消不了，所以騎太慢一歪就倒。
- **抓地力**：`gripUsage = 側向需求 ÷ 抓地力`。超過 `GRIP_WOBBLE` 開始晃（越快晃越大），超過 1 輪胎往外滑、車身往內倒（有上限 `SLIDE_CAP`，來得及救）。雨天用 `MU_WET`，壓在水坑、人孔蓋上時再乘 `SLICK_MU`。

**轉彎** `turnRate = g·tan(傾角) / v`，再受兩個上限限制：龍頭最多轉 `MAX_STEER`（低速不會原地打橫）、側向力不超過抓地力（太快會往外滑）。

**速度** 踩踏時速度趨近「踏頻對應的速度」`CRUISE·檔位·(1 − e^(−踏頻/CAD_K))`；上坡時檔位太重會「踩不動」（`strain > 1`）；下坡時重力照樣加速；沒踩或煞車時受滾動阻力、空氣阻力、坡度影響。

### 渲染（偽 3D）

- **鏡頭以道路方向為基準**：鏡頭基本上朝「車子所在位置的道路方向」看，只在橫向平滑跟隨車子（經典 OutRun 類做法），車子和路面的相對位置永遠是真實的。車頭方向畫在車子本身（輪子變橢圓、前輪往車頭方向露出來）。
- **轉彎鏡頭**：車子實際在轉的時候，鏡頭往轉的方向多看一點（偏轉 = 轉彎速度 × 0.35，最多約 15°，平滑約 0.5 秒），同時往彎道外側平移一點（最多 0.8 m）。旋轉中心是鏡頭本身，所以車子會稍微滑向畫面一側，看起來「正在轉」。這是剛體旋轉，不改變車子與路面的實際距離；遠景也跟著鏡頭實際看的方向轉。摔車時鏡頭停住，重播會記錄鏡頭角度。
- **道路取樣** `camera.points()`：以車子位置為基準，往前後每 1 公尺取樣道路中心。每一步用該段「中點」的方向推進，車子腳下正好是一個取樣點，所以不管車子在一公尺裡的哪裡，畫面都不會晃動或跳格。
- **路面用真正的 3D 投影畫** `drawRoad()`：和柵欄、樹用同一個 `projAt`。每 1 公尺一格（以世界座標對齊，條紋不會跟著車子跳），四個角投影到螢幕後由遠到近畫成多邊形，近的自然蓋住遠的。急彎時道路在畫面上變成橫向也照樣正確。相鄰兩格的接縫用同色描邊封住，螢幕縮放 1.25、1.5 倍時也不會透出底色。
- **下坡視角**：鏡頭偷看前方 30 公尺，如果路會往下掉，攝影機就慢慢升高（最多 2.5 公尺），地平線也稍微上移。主角固定在畫面同一個位置，所以攝影機越高焦距越短、主角看起來越小，坡頂後面的下坡路面就露出來了。
- **坡頂遮擋**：由近到遠記錄「比這一段更近的路面在畫面上最高到哪」（`V.clip`）。路邊物件、柵欄、建築畫的時候會裁掉這條線以下的部分，所以坡頂後面的東西看不到。上坡可以一路畫到畫面頂端；高過地平線的部分只畫道路兩旁約 30 公尺的草地，看起來是一座山丘，兩側仍看得到天空和遠山。
- **物件排序（只有一套）**：所有 3D 位置都經過同一個 `projAt`。地上的東西（水坑、人孔蓋、地面文字）先畫；其餘站著的東西（建築、柵欄、樹、車、人、主角）一律依鏡頭深度由遠到近畫。建築牆很長，切成小片各自排序（25 m 內每 1 m、60 m 內每 3 m、更遠每 8 m），轉角的建築才能正確擋住後面的車和樹。天空與遠山是平面圖層，夜晚效果與儀表最後疊上去。
- **主角**（`js/rider.js`）：在車子座標裡定義 3D 小骨架與車架，依車頭朝向旋轉、用小透視投影，每個部位畫成圓頭膠囊加細外框，依深度排序後由遠到近畫。往右轉時右手、右腳在近側完整露出，左手被背擋住；大腿平常排在軀幹後面，偏轉超過約 20° 時近側大腿才蓋過背部；看得到的那一側身體加漸層陰影；背號貼在背部平面上；安全帽頂的白線只畫朝向鏡頭的部分。坐墊前半段排在大腿後面被擋住；尾燈在後輪外緣後方的擋泥板末端。
- **夜晚**：整個畫面蓋一層放射狀的黑暗，車燈開著時中間亮、範圍大；路燈光暈用 `lighter` 疊加；最後畫雨絲。

### 測試在測什麼

測試裡有一個「自動駕駛」，用的就是遊戲同一套物理：每 1/60 秒讀取車子的橫向位置、車頭夾角、速度，往前看約 1 秒的彎道，算出該傾多少、換算成方向鍵要按多少，並預判 1 秒後車頭的方向來修正。速度不夠就踩踏、太快就煞車。隨機晃動用固定的亂數種子，結果可以重現。
